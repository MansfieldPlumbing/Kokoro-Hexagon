## The campaign

One goal: ordinary text on the phone to speech from the speaker, every model stage computed on Hexagon by our own
code. Production path:

Text -> CoreLib phonemizer -> Kokoro token IDs -> ALBERT -> duration/prosody predictors + text encoder -> decoder ->
generator + harmonic source -> PCM -> AAudio.

Every task either removes a missing model boundary or protects a verified one. No fixture or infrastructure work
unless a model-integration gate exposes a specific blocker. Optimization (per-voice caching, style folding at voice
load, thread/DMA tuning, long-sentence streaming) waits until the first full short sentence works.

## Next: ALBERT on Hexagon (team direction 2026-10-09), then predictors

Entry point: `./Invoke-KokoroHexagon.ps1`. ALBERT capture and per-linear error are done
(`docs/results/albert-weight-error-20261009.md`: A16W8 41-48 dB per linear, A8 not viable).

1. ALBERT on Hexagon. Every operator runs on SM8550 against the stock capture, each with an entrypoint command: linears
   (`AlbertLinear`, 41.4-48.8 dB), LayerNorm (`AlbertLayerNorm`, 52.9-73.8 dB), gelu_new (`AlbertGelu`, 67.4-72.0 dB),
   attention core (`AlbertAttention`, q and k rescaled per head), embeddings + LayerNorm (`AlbertEmbed`, 76.0 dB). Receipts:
   `docs/results/albert-*-sm8550-20261009.md`. Next: one job from token ids to `d_en` (embed, LN, mapping_in, 12 x [q, k, v,
   attention, dense + residual, LN, ffn, gelu, ffn_output + residual, LN], bert_encoder) with the shared layer's 5.5 MB of
   W8 weights resident in VTCM, compared with `bert_dur` and `d_en`. The LayerNorm kernel needs one input LSB across
   channels, so the residual stream is stored per tensor and the residual adds use the combine's Residual mode (Q15 ratio
   < 1); plan every LSB from calibration sentences other than the test sentence, as the decoder's job input does.
2. Predictors, alignment and text encoder on Hexagon from the DSP's `d_en`, feeding the existing decoder + generator (MNN `lstm_ops.cc` for the BiLSTMs);
   acceptance on SM8550 against pinned stock.
3. Ordinary text on the phone to AAudio, the harmonic source drawing its own randomness.

Implement on Hexagon and connect, in stock order (`kokoro/model.py` `forward_with_tokens`, `kokoro/modules.py`, pinned
`dfb907a0`): `predictor.text_encoder` (DurationEncoder: 3 BiLSTMs with AdaLayerNorm), `predictor.lstm` and
`duration_proj` (sigmoid, sum, round), alignment (`repeat_interleave` as a gather), `F0Ntrain` (shared BiLSTM; F0 and N
blocks reuse the decoder's `AdainResBlk1d` kernels), and `text_encoder` (embedding, 3 x conv + LayerNorm + LeakyReLU,
BiLSTM). New kernels: LSTM cell and recurrence, LayerNorm, sigmoid, gather. Their live outputs replace the captured
asr, F0 and N.

Acceptance: captured ALBERT output -> live DSP predictors and text encoder -> existing DSP decoder + generator -> PCM on
SM8550, with intermediate tensors and propagated PCM error compared against pinned stock. A kernel passing alone is
evidence, not the stage.

Then: ALBERT on Hexagon fed by the phone's `CoreDriver.Run(text).SymbolIds`. The style row is
`pack[len(ps)-1]` with `ps` the stock phoneme string (its character count), never the raw text length or the token
count with BOS/EOS. Then text entered on the phone to AAudio, with the harmonic source drawing its own randomness.

## GitHub Actions (proposed, not built)

Hosted, PowerShell only, reusing existing scripts: parse and `Test-PowerShellCasePair`; ratchet data validation; push
hygiene (no build output, identifiers or secrets); deterministic emission hashes for unchanged kernels; phonemizer
token IDs against frozen expectations; source and checkpoint pin checks. Hosted runners have no `build/` captures, so
inputs must be immutable and hash-verified. Phone, FastRPC and PCM ratchets stay separately authorized hardware gates
with their own receipts; no unrestricted self-hosted runner on the workstation or phone.

## Pitfalls turned into checks

PCM offset from the layout; case-only names and automatic-variable assignments (`Test-PowerShellCasePair`);
comma-joined `-File` arrays; pipelines unrolling arrays (use objects); `git` failures under `Stop` (check
`$LASTEXITCODE`); unmapped captures in `New-KokoroJobInput`; stage-tail fixtures now record `FrontFixture` and
`NoiseResFixture`.

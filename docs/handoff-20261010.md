## What changed

Stock Kokoro's decoder now speaks held-out sentences from a front end with no neural network: the compiled phonemizer,
`t_en` units sampled from a bank of stock captures, and durations, N and F0 predicted by PowerShell-learned tables from
an aligned linguistic stream. ALBERT, the five predictor BiLSTMs and the text encoder run only offline, to fill the
bank. Listening: "different, not worse". Receipts, in order:

1. `docs/results/prosody-substitution-zira-20261010.md`: Zira metadata does not replace the predictor. PCM SNR
   across different noise draws is about 19 dB.
2. `docs/results/unit-selection-smoke-20261010.md`: bank-assembled decoder inputs are bit-exact with stock.
3. `docs/results/unit-bank-curve-20261010.md`: 43,679-sentence bank (2.43M units, int16 `t_en` transparent).
   Sampled `t_en` converges to 1.17 against a 0.64 floor. Per-unit F0/N does not improve with bank size, and phrase N
   transplant fails.
4. `docs/results/substitution-refinement-20261010.md`: 1,140 decoder-verified substitutions. The symbol two to the
   right (R2) predicts the effect. Right-weighted `TargetCost` is lowered with exact parity.
5. `docs/results/prosody-two-stream-20261010.md`: N is the output log-energy envelope (r = 0.988). Two values per
   token reach 2.64 (ceiling). The table-predicted front end reaches 4.68, against 4.90 for unit-sampled prosody.

This front end makes a Kokoro variant. Phase-1 stock benchmarks still need the stock front end (AGENTS.md "Model
changes"). Benchmarks of this path are labeled as the variant.

## Pitfalls found

- PowerShell `-eq`/`-ne` on `[char]` ignore case. Phoneme symbols are case-significant (A/a, I/i, O/o, W/w, Y/y):
  use `-ceq`/`-cne` and Ordinal comparers. The pinned compiler compiles `[char] -ne` ordinally, a parity gap to
  report to PwshCompiler.
- The comma binds tighter than `+` and `-`: parenthesize index arithmetic.
- PSPerception `Invoke-PerceptRefine` admits by training contradictions (it chose features that do not generalize),
  and `Refine.ps1:460` assumes `SpecimenName`. Both are for the PSPerception repository.
- The driver resolves clause grammar for about 1 in 2,000 sentences, and the Moby capability table omits P, C and v.
  The experiments read Moby tags directly.
- Variable names ignore case: a `$t` loop overwrote a `$T` tile count.
- Dot-sourcing `Invoke-KokoroDevelopment.ps1` binds its parameters (`$Runs`, `$Case`, `$Path`, ...) in the caller's
  scope; a driver's `$Runs = 3` became 0 and the phone probe never returned. Use names the entrypoint does not declare.
- Inside a .NET method call, commas separate the method's arguments: `[Console]::WriteLine('{0} {1}' -f $a, $b)` passes
  three arguments. Parenthesize the `-f` expression.
- A `foreach` whose body prints a status string and emits an object collects both; print with `[Console]::WriteLine`.

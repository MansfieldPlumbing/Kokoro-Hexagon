## Pitfalls added

- An HMX `:single` read takes two 2 KiB croutons (Rs and Rs + dY; V81 HMX PRM 80-N2040-62 sec. 4.4.1, local copy in
  `build/reference-docs/`). With the croutons in different 1 MiB regions it faulted in the V73 simulator (exception 0x26);
  layouts keep HMX-read regions inside one 1 MiB page. Open: whether the limit is a translation page or an HMX region,
  and its size on the phone.
- Weights folded with per-channel input scales far apart lose W8 precision; 1x1 convs read identity windows in one scale.
- `q31(x * 2^16, W) = x W / 2^15`: multipliers applied to a 16-bit value shifted by 16 are Q15 gains.
- PowerShell: case-insensitive names (`$t`/`$T`), `@('a', 'b' + "`n" + 'c')` drops lines, `WriteAllLines` writes CRLF,
  `-like` brackets; see the pwsh-systems skill. Verify every intended line after an edit, and every dump in the step list.
- The phone must be awake (`adb shell input keyevent KEYCODE_WAKEUP`); the device harness now writes `Started=` first.

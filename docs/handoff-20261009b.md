## The loop

`tools/Kokoro.Evaluator.psm1` runs and scores DSP jobs on the phone; `tools/Kokoro.Ratchet.psd1` holds the accepted
values per case, the named setups, and the cases still blocked.

- `Test-KokoroRatchet`: every case, one line for the commit message (`ratchet: 1 run, 0 regressions, 0 improved, 6 blocked`).
- `Invoke-KokoroExperiment -Case <name> [-Setup <name>] [-Parameters @{...}]`: one candidate; one line; WAV and log row.
- `Compare-KokoroSetup -Case <name> -Setup Baseline, Threads3, Batch16`: setups fastest first, change against Baseline.
- `Test-KokoroKernel -Kernel <name>`: emit one kernel and check its bytes against the SDK assembler (cached).
- Experiment log: `build/evaluator/experiments.tsv` (keep, hold, discard, crash). Cached runs take 14-41 s.

Timing noise on SM8550, decoder + generator hello world: 106.9-110.2 ms over 5 unchanged runs (3.0%). A gain must
beat that; the ratchet's 3% allowance is measured, not assumed.

## Pitfalls turned into checks this session

- PCM offset: `Measure-KokoroPcmSnr.ps1` reads `PcmOffset` from the emission's `runner-layout.json`.
- Case-only name collisions and assignments to automatic variables (`$input`): `Test-PowerShellCasePair`
  (`C:/Dev/Pwsh-Development/tools/SharedLibrary.psm1`).
- `pwsh -File` joins arrays with commas: the evaluator and shared checks split them.
- Pipelines unroll arrays: `$list | Sort-Object` over a list of arrays yields scalars; use objects with named properties.
- Native commands do not stop on `$ErrorActionPreference = 'Stop'`: check `$LASTEXITCODE` after each `git` call.

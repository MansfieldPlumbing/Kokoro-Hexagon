## How -Whole works

`$configure` (dot-sourced) binds one section's sizes and offsets; `$bind i` rebinds section i. Inputs, weights,
records and the r25 DDR workspace of section 1 follow section 0's; VTCM is shared (max of both). Per-channel bodies
are emitted per section with labels suffixed `_c256` / `_c128` (empty suffix in single-section mode, so the proven
kernels emit identical bytes: checked for six kernels by skel SHA-256). The 60x front's ups[1] planes are
`body_leaky_up` (LeakyReLU 0.1) of the 10x mean, DMA'd from section 0's final tensor into VTCM. The admission wrapper
is built with the last section's frames (it bakes the config tile count).

## Pitfalls added

- `-File` with an array argument arrives as one string; call tools with arrays from a script file.
- Monitor commands run in bash, not PowerShell.
- A per-section value used before the section loop (the wrapper's frames) silently takes section 0's.

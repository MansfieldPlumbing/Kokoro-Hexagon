## Faults found on the phone, without the simulator

- A single residual scale per tensor made the phase gain K exceed int32 on quiet channels: per-channel
  residual scales, bounded so K <= 0.9 * 2^31.
- Stock Snake alpha can be negative: S is then negative, a signed Q31 multiplier (kernel unchanged).
- Conv output units were 256x off (`sum x Wq = 65536 A1 + 256 A2 + A3`): stage 0's C scored -0.03 dB.
  Located by dumping, in order, stage 0's K/M/S (exact), conv-input windows (66.05 dB) and HMX
  planes (-0.02 dB, then 65.47 dB after the fix), via `-Stage16StopAfter`/`-Stage16DumpPoint`.

Fixture build: 6 s (was over 12 minutes) with per-element work in `tools/Kokoro.CaptureKernels.psm1`
(expression trees compiled once per session) and statistics in `tools/Kokoro.CaptureMath.psm1`.

## Goal

PowerShell-emitted. Bar: about 42 dB raw PCM SNR against stock (judged by ear as indistinguishable).
SM8550 first; SM8635 (4 MiB VTCM) later through the recompute layout. Phonemes come from the team's
misaki-parity phonemizer (separate sidecar); until then the DSP steps run from captured stock inputs.

## How the 16-bit stage is built and checked

- Fixture: `tools/New-KokoroGenerator60x16Fixture.ps1 -CaptureDirectory <resblocks.3>,<.4>,<.5> -OutputDirectory build/<new>`
  (6 s). Captures used: `build/stock-resblock-capture-20261006T092246Z`, `build/generator-block4-capture-20261006`,
  `build/generator-block5-capture-20261006`. Per-channel residual scales bounded by the turns-gain
  contract; conv units `2^(L+8) sX sW_c`; bias in group 2 as `b / (256 sX sW_c)`.
- Emit and check bytes: `tools/Test-HexagonEmission.ps1 -Kernel KokoroGenerator60x16Run -OutputDirectory build/...`.
- Phone: `tools/Invoke-ResBlockRunProbe.ps1 -Graph Generator60x16 -CaptureOutputPath build/<new>.bin ...`
  (captures the whole workspace: branch 0, branch 1, final tensor, all 18 K/M/S records).
- Score: `tools/Test-KokoroStage16Diagnosis.ps1 -Workspace <bin> -FixtureDirectory <fixture> -CaptureDirectory <3 captures>`.
- Localize a fault without the simulator: emit with `-Stage16StopAfter n` and `-Stage16DumpPoint Stage|Windows|Planes`
  (Emit-HexagonProbe), run, score with `-DumpStage n` (Stage) or a windows/planes decode. The order that
  found this week's bugs: stage-0 K/M/S (exact), conv-input windows, HMX planes, stage output.
- Per-element build math lives in compiled kernels: `tools/Kokoro.CaptureKernels.psm1` (expression trees,
  compiled once per session) and `tools/Kokoro.CaptureMath.psm1` (verified, cached capture reads and
  per-channel statistics). Keep PowerShell off every hot math path, build tools included.

## Decisions and rules from this session

- Threads, not instruction packing: the packet scheduler is frozen on branch `frozen/packetizer`
  (estimates only, never run on a phone). Revisit after the V73 release.
- HVX slot rule: multiplies and full-Rt ops slots 2/3; shifts by Rt and simple ALU any slot
  (V73 HVX PRM 5.1.3 Table 5-2; assembler-checked).
- No HVX lock fallback until a run shows a lock failure; every worker's lock result is recorded.
- Commit and push were authorized for this campaign; keep receipts short with numbers, hashes, commit.
- Never name the phones in the repository; select by `ro.soc.model`. adb at `C:\backup\Android\platform-tools\adb.exe`.
- Python only executes stock PyTorch (captures); everything else is PowerShell.

## Pitfalls hit

- PowerShell variable names are case-insensitive: `$B`/`$b`, `$S`/`$s`, `$K`/`$k`, `$sw`/`$sW`, `$N`/`$n`
  collided in the fixture builder. Scan with the AST for case-folded duplicates after edits.
- `R` is an alias (Invoke-History); do not name helpers `R`.
- Background wait loops that never meet their condition run for hours: give them a failure exit.
- The libqurt.a stubs (PMU, futex, HVX lock, hvx_get_units) are not exported by the DSP image: emit their
  traps inline. `qurt_thread_create/join/exit` are exported.
- `pwsh -File` passes arrays as one comma-joined string: call scripts in-process when passing arrays.
